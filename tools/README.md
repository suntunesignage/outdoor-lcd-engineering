# Tools

A future home for practical engineering calculators, checklists and diagnostic aids.

## Planned coverage

- Documented input units and assumptions
- Transparent formulas and references
- Meaningful validation examples
- Applicability limits and uncertainty

## Status and contribution standard

Foundation only: no validated tools are published here yet. These topics are directions, not claims about SUNTUNE products or field results.

Future contributions must distinguish **Established engineering principle**, **Engineering estimate** and **SUNTUNE-verified data** where applicable. Mark missing verification `[VERIFICATION REQUIRED]`, document sources and limitations, and obtain human approval before merging.

Document formulas, units, dependencies, reproducible validation and operating bounds. Label calculated estimates explicitly; a tool output must not be presented as a verified product specification.

See [contribution requirements](../CONTRIBUTING.md) and [return to the library](../README.md).
